## 一、模型总览

国安动态定价系统由三个核心模块组成：

| 模块 | 功能 | 核心文件 | V8.1 变更 |
|------|------|----------|-----------|
| **规则引擎** | 上座预测（V5.6 规则×对手分级） | `src/rule_engine.py` | EMA 默认关闭，≥8场/级门禁 |
| **对手分级** | KMeans K=4 聚类（S/A/B/C） | `src/classify.py` | — |
| **定价矩阵** | 6档起售价 + 弹性系数 → 优化价 | `src/pricing_v5.py` | **弹性分级差异化** |
| **上下文检测** | 自动检测赛前状态（连败/短休等） | `src/csl_context.py` | — |
| **动态优化器** | 量价平衡 + 收入底线 + 跨档约束 | `src/dynamic_optimizer.py` | **量价锚可涨 + 容量约束 + 安全阀分级** |

定价逻辑链：
```
对手名称 → classify_opponent_tier() → S/A/B/C级
         → csl_context.detect_ctx() → 触发乘数
         → rule_engine.predict()    → 预测上座
         → get_pricing_tier()       → 定价档(S_S/S_A/S_B/S_C/S_Cminus)
         → DynamicPricingOptimizer  → 优化后6档价格
```

## 五、优化器策略 — V8.1

### 动态权重
- 高上座（≥11,000）→ 收入权重 0.80
- 中上座（≥8,500）→ 收入权重 0.60
- 中低上座（≥6,500）→ 上座权重 0.60
- 低上座（<6,500）→ 上座权重 0.80

对手级别 caps：S=1.0, A=0.65, B=0.50, C=0.35

### V8.1 关键变更

**1. 量价锚（T1/T2）高需求可涨价**
- 旧：`min(p_opt, p0)` — T1/T2 在任何情况下都不涨价
- 新：供需比 > 85% 且 rw ≥ 0.6 时，基于容量紧张度允许涨价（上限 +5%~12%）
- 效果：申花德比 T1 ¥310→¥330 (+6%), T2 ¥400→¥420 (+5%)，总收入 +6.7%

**2. 安全阀分级豁免**
- 旧：predicted < 13,000 → 统一降级 balanced（申花 12,852 永远无法用 revenue 策略）
- 新：S级阈值 11,000, A级 12,000, B/C级 13,000

**3. 份额分配容量约束**
- 旧：事后 min(q, cap) 截断，高需求时 T2-T6 超容量
- 新：迭代重分配溢出量，确保所有档位在容量内

**4. EMA 赛后校准（默认关闭）**

2026-05-27 全量重置 tier 因子为 1.0。看板页顶「启用 EMA 校准（实验）」默认关；开启后样本 < 8 场/级强制 1.0，防止小样本恶化 MAE。
- Tab2 历史定价每场赛后自动调用 `rule_engine.update()`
- α=0.20，校准因子 bounded [0.3, 2.0]

### 两种模式
- **revenue**：T1/T2 量价锚（可涨）, T3/T4 弹性区, T5/T6 收入锚
- **balanced**：T1-T3 降价抢量, T4-T6 涨价补收入（rw ≤ 0.4 自动激活）

### 约束
- 档位间距 ≥ 10%, T3→T4 ≥ 18%
- 跨级 ≤ upper_base / 1.05
- 涨价单档增量 ≥ ¥10,000, 降价增量 ≥ 100人
- 变化 < 3% 不调, 整体Δ < max(0.5%, ¥5,000) 全回退

## 九、胜负不对称性发现（2026-06-18）

### 核心发现：输球有强惩罚，赢球无明显加成，正面效应来自排名而非连胜

对 2023-2026 全部主场赛事（56场）的系统回测揭示了一个行为经济学规律：**球迷对主场输球的负面反应远强于对赢球的正面反应**。赢球是工体的基线预期，不产生增量购票；而输球——尤其是连败——会显著抑制上座。

### 数据证据

**负面规则验证（效应强且一致）**：

| 规则 | 触发场次 | 实际/预测均值 | 典型案例 |
|------|:--------:|:----------:|---------|
| `poor_home_form`（近3主场≥2负） | 2 | 0.97x | 2025梅州 21.5%→0.4%, 2026海港 29.3%→0.4% |
| `consecutive_home_losses`（连败） | 1 | 0.99x | 2026大连 0.7% |
| `away_winless_losses`（客场全败） | 3 | 0.87x | 2026成都 0.6% |
| `heavy_home_loss`（惨败） | 1 | 1.59x → 1.36x | 2025天津（德比守卫修复后） |

**正面规则验证（信号弱或不一致）**：

| 候选规则 | 触发场次 | 实际/预测均值 | 结论 |
|---------|:--------:|:----------:|------|
| 连续2主场胜（S级） | 2 | 0.997x | 无效应，S基值已饱和 |
| 连续2主场胜（A级） | 2 | 1.095x | 有信号但样本仅2场 |
| 连续2主场胜（B级，无top3） | 3 | 0.990x | **无效应**，方向不一致 |
| 连续2主场胜（B级，有top3） | 3 | 1.124x | top3_form的1.08x标定偏低 |

### 行为经济学解释

这一现象符合**损失厌恶**（Loss Aversion）理论：

| 现象 | 效应 | 机制 |
|------|------|------|
| 主场连败/低迷 | 强负面 ×0.77-0.82 | 球迷失望 → "球队不行了" → 不买票 |
| 主场连胜 | 无明显效应 | 工体赢球是预期 → 不产生增量购票 |
| 排名前三 | 正面 ×1.08 | 争冠话题 → 带动广泛关注（但1.08可能偏低） |

**关键逻辑**：
- 国安作为传统强队，主场赢球是**预期**而非**惊喜** → 赢球不驱动增量
- 输球是**意外打击** → 强烈负面反应 → 上座下降
- 排名（top3_form）捕获的是**争冠氛围**，与单场胜负不同 → 正面但偏弱

### 模型设计含义

1. **负面规则优先**：`poor_home_form`、`consecutive_home_losses` 等规则有充分的实证支持，乘数标定可靠
2. **不设正面连胜规则**：数据不支持"连胜溢价"，B级无top3时连赢3场比值0.99x（完全无信号）
3. **`top3_form` 可调高**：有top3时连赢场次仍偏低12%，1.08→1.12 可能更准（待更多样本验证）
4. **`heavy_home_loss` 德比守卫**：输给德比对手（申花/山东）的大败不触发惨败惩罚——德比输球是情感对决而非实力崩盘，球迷反而更热情（2025天津实际14776 vs 预测9265）

## 十、策略回测操作路径（待实施）

> ⚠️ 当前模型仅提供定价建议，俱乐部尚未实际执行。以下为回测所需的业务操作流程。

### 核心问题

赛前模型给出推荐价 → 赛后拿到实际销售数据 → 需要三方对比才能评估策略有效性：

```
模型推荐价  vs  俱乐部实际执行价  vs  实际销售结果
```

### 操作路径

#### 阶段 1: 赛前（T-7 天）— 保存定价建议快照

每场主场比赛前，保存模型推荐价到 `data/backtest/{日期}_{对手}.json`：
- 6 档推荐价格、基准价格
- 预测上座、预测收入
- 策略模式（revenue/balanced/attendance）及 rw 权重
- 触发的上下文规则
- 保存时间戳

→ 需实现：Tab1「保存建议」按钮

#### 阶段 2: 赛中 — 记录实际执行价

俱乐部可能不完全采纳模型建议，需要记录：
- 6 档实际执行价格
- 如与模型不同，备注原因（锁价/赞助商协议/董事会决策等）

→ 需实现：Tab1 或 Tab2 实际执行价录入

#### 阶段 3: 赛后（T+1 天）— 跑三方对比

1. 从 parquet 拉实际销量和实际收入（已有函数）
2. 用实际执行价跑优化器 → 场景收入
3. 用模型推荐价跑优化器 → 机会收入
4. 计算：采纳率、机会成本、策略命中

#### 阶段 4: 赛季末 — 汇总报告

- 预测 MAE 收敛趋势
- 策略采纳率（俱乐部采用比例）
- 未采纳的累计机会成本
- 各策略模式效果排名

### 实施优先级

| 优先级 | 功能 | 依赖 | 说明 |
|--------|------|------|------|
| **P0** | 赛前快照保存 | 无 | Tab1 加按钮 → 写 JSON，下场比赛就能用 |
| **P1** | 赛后自动对比 | P0 | 读快照 + 实际数据 → 对比表（已有部分在 Tab2） |
| **P2** | 实际执行价录入 | P0 | 支持手动填入俱乐部实际价格 |
| **P3** | 赛季汇总报告 | P0+P1 | 积累 5+ 场后自动化 |

## 十二、4 档简化定价分析（2026-06-04）

### 核心发现：6 档 → 4 档，减少价格梯度反而增收

**反直觉结论**：在工体散票市场，更少的价格档位比更多的档位赚更多钱。

### 数据分析

7 场已赛数据回测：

| 档位 | 当前 | 上座率 | 问题 |
|------|------|:--:|------|

## 十四、动态对手分级体系（V6.0）

### 14.1 设计动机
- 静态 KMeans K=4 集合无法响应赛季中球队状态变化
- 海港 A↔B 手动调整：每次改 3 个文件
- 升班马零数据冷启动靠纯保守假设
- 山东 2026 战绩差仍按 A 级定价

### 14.2 双维度评分模型
**ST 实力分** (0-100)：ELO(40%) + PPG(30%) + 近5场(20%) + 净胜球(10%)
**AP 吸引力分** (0-100)：历史上座(40%) + 德比加成(25%) + 当年票房比(20%) + 话题度(15%)

### 14.3 不对称阈值（下调易/上调难）
- C档：ST<35 或 AP<22
- A档：ST≥70 且 AP≥28
- S档：申花硬锁
- 默认 B档

### 14.4 数据源
- ELO：MCP CSL 2023-2026 比赛结果（~720场）
- 上座：all_unified.parquet（2023-2026 国安主场票务）
- 积分榜：MCP csl_standings
- 话题检测：自动从积分榜排名推导 title_race/relegation/new_promoted

### 14.5 销速交叉验证
- D4 销量 / 0.60 = 预测最终销量
- 偏差 > 20% 触发人工审查
- 赛中修正乘数：D7 实际/预期 × 0.5 平滑

### 14.6 赛季中调整
- 每轮自动更新 ELO
- 月度档位变更报告
- 硬锁不可移除（申花S/山东A）
