# 需求驱动定价模型 V7 — 深度研究

> 日期：2026-06-25 | 基于 FIFA 世界杯 + MLB/NBA + 航空收益管理

---

## 一、FIFA 世界杯定价体系

### 1.1 核心原则：座位决定价格，不是对手

FIFA 不对"巴西 vs 德国"和"巴拿马 vs 沙特"用不同定价。同一轮次、同一类别座位，所有比赛同价。

```
FIFA 2026 定价矩阵（美元）:
               Cat 1    Cat 2    Cat 3    Cat 4(主办国)
小组赛           $220     $165     $105     $35
32强            $280     $210     $135     $45
16强            $320     $240     $155     $55
8强             $420     $315     $205     $75
半决赛          $750     $560     $365     $125
决赛           $1,100    $825     $535     $185
```

**关键洞察**：FIFA 按"比赛阶段"×"座位类别"定价，对手是谁不影响基础价。需求差异通过**二级市场**（转售）体现，不是官方定价。

### 1.2 为什么对手驱动定价不合适

| 对手驱动 | FIFA 模式 |
|----------|-----------|
| 申花→S档12600、海牛→C档5700 | 所有小组赛 Cat1=$220 |
| 德比加价25% | 淘汰赛自然溢价 |
| 人为判定"强队""弱队" | 市场自己定价 |
| 球迷争议"凭什么申花贵3倍" | 透明、公平 |

### 1.3 FIFPro 转售市场定价

FIFA 官方不搞对手差价，但**转售市场**自然形成：
- 决赛 $825 → 二级市场 $3,000+
- 巴西 vs 阿根廷 → 溢价 3-5x

这恰好证明：**需求信号在市场端，不在定价端**。定价端做好座位分级和轮次阶梯，需求端让市场自己出价。

## 二、MLB/NBA 动态定价实践

### 2.1 旧金山巨人队（MLB 先驱）

```
17个座位类别 × 3个需求等级 = 51个价格点
需求等级: Super-Premium > Premium > Regular > Value
每场根据对手+先发投手+天气+战绩自动调整等级
```

**调整幅度**：单场 ±15%，赛季累计 ±30%。不是"申花贵3倍"，而是"同区座位申花场比普通场贵15%"

### 2.2 NBA 动态定价

```
球馆分 8-12 个价格区
每区基准价 ± 动态因子:
  对手实力指数 × 0.3
  主队战绩 × 0.2
  周末/假日 × 0.15
  客队球星 × 0.15
  售罄速度 × 0.2
```

**关键**：动态因子幅度控制在 ±25% 以内，不是翻倍。

## 三、对国安定价的启示

### 3.1 核心问题

当前模型的问题不是"对手驱动"，而是**价差幅度过大**：

```
当前: 申花S=12600 vs 海牛C=5700 → 2.2x 差距
FIFA: 决赛Cat1=$1100 vs 小组Cat4=$35 → 31x 差距（但这是座位+轮次，不是对手）
MLB: 同座位不同对手 → 最多 ±15%
```

国安应该学 MLB：**同一座位，不同对手价差控制在 ±15%，而不是 ±50%。**

### 3.2 修正模型

```
每区基准价 = f(座位属性: 视角、距离、遮阳)
每场调价   = f(需求信号: 预测上座、德比、周末、暑假) → ±15%
稀缺度     = f(销速: D4已售/容量) → ±10%
```

**不是**：申花场 T1 从 260 涨到 400（+54%）
**而是**：申花场 T1 从 260 涨到 299（+15%），海牛场 T1 从 260 降到 221（-15%）

### 3.3 座位属性基价（替代 T1-T6）

基于工体实际座位数据，每个区的价值由三个客观属性决定：

| 属性 | 权重 | 说明 |
|------|:---:|------|
| 视角评分 | 50% | 距中线距离 / 角度偏转 |
| 距离评分 | 30% | 距球场距离 / 层数 |
| 舒适评分 | 20% | 遮阳 / 独立座位 / 出口距离 |

每个区计算一个属性分数（0-100），映射到基价范围 ¥100-1,500。不人为分成 6 档——96 个区就有 96 个基价（实际可聚类为 10-12 个价格带）。

## 四、新定价公式

```
P(区, 场次) = 基价(区)
            × (1 + 需求因子)      # 预测上座率映射到 ±15%
            × (1 + 稀缺因子)      # 销速映射到 ±10%
            × (1 + 时间因子)      # D-14到比赛日 -10%→+5%

需求因子 = (总预测上座 / 总容量 - 0.7) × 0.5   # 70%上座率=中性，100%=+15%
稀缺因子 = (区预测需求 / 区容量 - 0.7) × 0.3   # 70%=中性，>90%=+6%
时间因子 = max(-0.10, min(+0.05, -0.10 + 0.15×(D-开售)/14))
```

**约束**：
- 总调幅不超过 ±25%（单场任一个区）
- 相邻区价差不超过 30%
- 升价需人工确认（降价自动）

### 4.1 模拟：山东泰山 7/4

```
总预测: 12,608 → 上座率 84% → 需求因子 = (0.84-0.7)×0.5 = +7%

以 S123（T3主力区，基价¥440）为例:
  历史占比 6% → 预测需求 756 张
  区容量 800 → 稀缺度 95% → 稀缺因子 = (0.95-0.7)×0.3 = +7.5%
  时间因子 = 0（开售日）
  P = 440 × 1.07 × 1.075 × 1.0 = 506 → 比静态T3=480涨5%

以 S331（T1热门区，基价¥260）为例:
  历史占比 8% → 预测需求 1,009 张
  区容量 1,500 → 稀缺度 67% → 稀缺因子 ≈ 0
  P = 260 × 1.07 × 1.0 = 278 → 比静态T1=260涨7%
```

## 五、与当前系统对比

| | 当前 V6 | 新 V7 |
|------|------|------|
| 定价粒度数 | 6 档 | 96 区（10-12 价格带） |
| 对手影响幅度 | S vs C = 2.2x | ±15% |
| 德比处理 | +25% 乘数 | 需求因子自然体现 |
| 升班马 | 硬编码 C | 低上座 → 需求因子为负 |
| 理论基础 | 统计聚类 | FIFA + MLB + 航空收益管理 |
| 用户感知 | "申花凭什么这么贵" | "好座位贵、大场面贵一点" |

## 六、实施要点

1. **先建座位属性表**——工体 96 区视角/距离/容量数据
2. **聚类价格带**——96 区聚类成 12 个价格带，初期不带 96 个不同价
3. **需求因子校准**——用 2023-2025 数据回测最优调幅范围
4. **灰度上线**——先输出建议价不做实际调价，跑 5 场验证
5. **用户沟通**——"座位定基价，场面定浮动"，清晰透明
