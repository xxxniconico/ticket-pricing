## 四、信号设计 V1(初稿,发现缺陷)

```python
if p_home >= 0.55 and opponent_tier >= B:  # 误:应该是 A 或 S
    return 1.05
if p_home <= 0.35 and opponent_tier >= B:
    return 0.92
```

**问题**: C 级对手(57% 基值本来就低)即使市场看好国安胜(66.4%),也不应再加 +5%,否则过度激励低价值场。**FIFA 报告原则**: market signal 对 big match 才显著。

---

## 五、修正设计 V2(推荐)

```python
def odds_signal(p_home: float, opponent_tier: str, base_qty: int) -> float:
    """
    仅在以下条件触发:
    1. 对手 >= A 级(高价值场,赔率信号才显著)
    2. 或 |p_home - 0.50| >= 0.15(赔率信号极端,无论对手)
    """
    is_big_match = opponent_tier in ("S", "A")

    if is_big_match:
        if p_home >= 0.55:  # 市场看好国安
            return 1.05   # +5% 信心溢价
        if p_home <= 0.35:  # 市场看低国安
            return 0.92   # -8% 反映悲观预期
        return 1.0

    # 小场: 仅极端信号生效
    if p_home >= 0.65:
        return 1.03
    if p_home <= 0.30:
        return 0.95
    return 1.0  # 中间地带不触发,避免噪音
```

**关键不变量**(铁律补丁):
- 与现有 `top3_form` / `derby` 乘数 **取较温和那个**,不重复激励
- 触发时仍受 `PENALTY_FLOOR=0.35` 保护
- 仅使用 T-7d 赔率(赛前短期波动过滤,FIFA 推荐)

## 七、V5.6 接入建议(下一步)

**推荐**: **继续推进**,但降级为"次要信号"。理由:

1. **零成本叠加**: 已有 14 个乘数,赔率只是第 15 个,即使相关性弱也不引入偏差
2. **大场能验证**: 8 月份有国安 vs 上海申花(A 级德比)、vs 上海海港(S 级)等大场,可以累积大场验证数据
3. **FIFA 共识**: 市场信号是体育定价"行业标准",即使国安数据样本小,理论可解释性强

**实施清单**(给后续 sprint):
- [ ] `src/odds_fetcher.py`: 周更一次,缓存到 `data/raw/odds/`
- [ ] `src/implied_prob.py`: 去 vig 加权(低 vig 公司权重高)
- [ ] `src/csl_context.py`: 新增 `odds_signal()` 函数(V2 设计)

- [ ] 看板 V8: 新增"赔率信号"模块显示 p_home / 公司分布 / 触发详情

**预期收益**:

- C 级场几乎无影响(信号弱)
