## Phase 2: 模型重建 📐

### Task 2.1 — 2025-Only V4 训练
**文件**: `src/calibrate.py` (新增函数)
**做什么**: `build_attendance_model_v4()` — 仅用2025数据，6特征OLS
**特征**:
```python
features = [
    "recent_form_5",       # 滚动5场胜率
    "lost_to_bottom",      # 近3场输保级队
    "opp_rank_live",       # 实时积分榜排名(新!)
    "is_derby",            # 德比
    "is_weekend",          # 周末(替代day_of_week)
    "is_double",           # 双赛周
]
```
**注意**: 用 `standings_2025_by_round.parquet` 查每场比赛当时的对手排名
**负责人**: Cursor（照Task 1.1的数据写OLS）

### Task 2.2 — 2026增量迭代
**文件**: `src/calibrate.py` (修改 `build_attendance_model_v3`)
**做什么**: 改为 `build_attendance_model_live()` — 2025全量 + 2026已完赛
**逻辑**: 读取 `is_partial==False` 的2026场次，追加到2025训练集
**负责人**: Cursor

### Task 2.3 — 分级弹性估计
**文件**: `src/elasticity.py` (新增函数)
**做什么**: 按S/A/B/C四级分别拟合ε（从交易数据）
**当前**: 全局ε=-2.5
**目标**:
```python

    "S": -0.5,   # 德比刚性(文献推测, 待数据验证)
    "A": -1.5,   # 强队
    "B": -2.5,   # 中游(2025数据拟合)
    "C": -3.0,   # 弱队
}
```
**负责人**: Cursor（调 `fit_elasticity_from_transactions` 按级别分组）
