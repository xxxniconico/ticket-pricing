# V8 卡片统一 + 扩充规格

## 任务

修改 `dashboard/app_v8.py`，实现以下改动：

## 1. KPI 卡片提到全局（Tab 之前）

当前 `render_kpi_cards()` 在 Tab 1 内部调用，历史 Tab 看不到。改为在 `main()` 中、4 个 Tab **之前**渲染，两个 Tab 都能看到同一组卡片。

## 2. 扩充卡片内容（从 5 个 → 8 个）

当前 5 个卡片：
- 下一场对手 | 赛季 MAE | 收入底线 | 已赛主场 | 对手分级

扩充为 8 个卡片，分两行（第一行 4 个 + 第二行 4 个）：

### 第一行：赛季概览
| 卡片 | 主值 | 副值 |
|------|------|------|
| 国安排名 | `#N` | `积分: X分 (扣Y分)` |
| 主场战绩 | `W-D-L` | `已赛 N/15 主场` |
| 赛季 MAE | `1,035 张` | `MAPE 10.9% · N=7` |
| 近5场形态 | `W D W L W` | `3胜1平1负` |

### 第二行：下一场聚焦
| 卡片 | 主值 | 副值 |
|------|------|------|
| 下一场对手 | `vs 武汉三镇` | `06-27 周六 · 第16轮` |
| 对手分级 | `A 级` | `定价: A·标准定价 · T1=¥260` |
| 预测上座 | `12,500 张` | `80%区间 [11,000-14,000]` |
| 预测收入 | `¥385万` | `vs 基准 ¥372万 (+3.5%)` |

（如果下一场是客场，第二行 4 个卡片显示下一个主场的信息，并标注"下一场为客场，以下为最近主场"）

## 3. 历史定价 Tab 也展示卡片

在 Tab 2（历史定价）顶部，展示相同的 8 个卡片行（因为卡片是赛季级数据，不随 Tab 变化）。实现方式：把卡片渲染放在 `main()` 中 Tab 之前，不放在 Tab 内部。

## 4. 删除独立进度条

当前 `render_kpi_cards` 底部有独立的进度条，改为嵌入"已赛主场"卡片的副值中（已有"已赛 N/15 主场"文字）。

## 技术约束

- 不改 src/ 下任何文件
- 卡片用 `st.columns(4)` 分两行，CSS class `kpi-card` 不变
- 预测上座和预测收入使用 `compute_home_predictions()` 和 optimizer 结果
- 预测收入卡片只在有 target_match 时显示（需要 optimizer 计算）
- 保持暗色 Linear 风格
- 无 st.dataframe / pd.to_html
