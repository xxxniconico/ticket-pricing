# 票务定价模型优化方案 v4.1

> 核心原则：2025=训练集，2026=验证/迭代，精简特征

---

## 0. 数据架构修正

```
训练集:  2025赛季 16场CSL主场（全量完整数据）
验证集:  2026赛季  6场CSL主场（排除5/23预售）
迭代:    每场2026赛后 → 追加到训练 → 增量重训
```

**为什么2025-only训练**：
- 单一赛季内比赛条件一致（票价体系、球队阵容、赛程密度）
- 2026有罚分/升降级 → 市场结构不同 → 应作为验证而非训练
- 2025有16场（vs之前2025旧格式15场），样本足够

---

## 1. 精简特征集（6个）

只保留统计显著且预测安全的特征：

| # | 特征 | 类型 | 预期符号 | 理由 |
|---|------|------|----------|------|
| 1 | `recent_form_5` | 连续[0,1] | **+** | 近5场全赛事胜率，信心指标 |
| 2 | `lost_to_bottom` | 二值 | **−** | 近3场输保级队，最强单一因子 |
| 3 | `opp_rank_live` | 整数[1,16] | **−** | **实时积分榜排名**（非年终） |
| 4 | `is_derby` | 二值 | **+** | 申花/天津/山东 |
| 5 | `is_weekend` | 二值 | **+** | 替代day_of_week，减少共线性 |
| 6 | `is_double` | 二值 | **−** | 双赛周疲劳效应 |

**剔除的特征**：
- ❌ `day_of_week` → 替换为 `is_weekend`（消除与derby的共线性）
- ❌ `days_since_last` → 效应近乎0（系数0.005），且与is_double相关
- ❌ `repeat_ratio` → 同期指标，预测时不可知；且2025-only训练下样本更少
- ❌ 天气 → 2025主场全在4-11月，气温降水方差小，加入反增噪声

## 2. 对手排名实时化（关键改进）

### 当前问题
```python
# ❌ 2026比赛查2025终榜排名
opp_rank = get_opponent_rank_2025("河南队")  # → 永远是16
```

### 解决方案
```python
# ✅ 查实时积分榜
standings = fetch_csl_standings()           # CSL Dashboard JSON
opp_rank = get_opponent_standing("河南队", standings)  # → 现在是12
```

**2025回填**：从赛果逐轮重建积分榜 → 每场比赛当时的对手排名
- 已有2025全30轮比分 + 罚分信息
- 可编程重建每一轮后的积分榜快照

**2026动态**：直接读 `fetch_csl_standings()` 实时数据

---

## 3. 2026增量迭代机制

```
每场2026主场完赛后:
  1. 该场散票数据放入 data/raw/2026/
  2. 运行 retrain:  2025全量 + 2026已完赛场次
  3. 下一场预测自动使用最新模型
```

好处：
- 样本逐渐增长（16→17→18...）
- 2026特有的市场变化（罚分、新队）逐步被模型吸收
- 不像之前把半赛季的2026和2025混在一起训练
