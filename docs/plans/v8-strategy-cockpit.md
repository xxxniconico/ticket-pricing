## 功能需求

### 1. 顶部 KPI 卡片行（4列）

- 剩余目标: ¥18.8M / 66,461张 (8场)

- 升班马状态: ⬆ 辽宁/重庆 C级 → 待验证 (辽宁赛后触发)

### 2. 下一场盯盘区
- 读 CSL 数据找 next_home
- 用 V5.3 rule_predict + detect_ctx 实时预测
- 对比 H2 JSON 中对应场次的目标
- 标注偏差：预测 vs 目标、策略是否吻合、盯盘触发条件
- 显示定价矩阵（6档基准价）
- 累计追踪状态（已完收入 + 本场目标 vs 全年目标）

### 3. 逐场策略表（同现有，优化）
- 8场全列，标注已完/剩余
- 每场：日期/对手/分级/预测/策略标签/目标收入/T1-T6基准价/风险标记
- 颜色编码：revenue_priority=红, revenue_tilt=黄, balanced=绿
- 升班马行加 ⬆ 标记
- 已完成的比赛从 JSON 读取（如果未来更新 JSON）

### 4. 累计追踪表
- 逐行：日期/对手/目标收入/累计目标/实际收入(未赛留空)/偏差
- 底部汇总行
- 实际列目前为 "—"，设计为赛后手动填入或读 parquet
