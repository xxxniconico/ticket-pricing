## Phase 2: 分档位需求模型 📊

### 2.1 为什么需要
一层/二层/四层是不同的产品，价格弹性差异显著：
- 一层前排（¥580-1380）: ε ≈ -1.0（刚性，看球体验导向）
- 四层后排（¥160-340）: ε ≈ -3.5（弹性，价格敏感）

当前模型把所有人混在一起做单一体量预测 → 定价优化效果打折扣。

### 2.2 实现路径
```
每个档位独立回归:
  ln(demand_tier_i) = f(form, rank, derby, weekend, weather, repeat_ratio)
  + tier_specific_features (该档位历史占比、前后排偏好)
```

输出: 6个档位各自预测上座数 → 独立容量约束 → 独立定价优化

### 2.3 数据支持
- 已有: 每行座位→区段→楼层→排数
- 可计算: 每个档位的场均售出、前排占比、均价弹性

## Phase 3: 用户级价格敏感度 👤

### 3.1 分层弹性
| 用户层 | 占比 | 推测ε | 策略 |
|--------|------|-------|------|
| 铁粉(5+) | 4.4% | -0.5 | 高价不敏感，VIP套餐 |
| 常客(3-4) | 8.5% | -1.5 | 季票/套票锁定 |
| 偶尔(2) | 14.6% | -2.5 | 中等价位主力 |
| 一次性 | 72.5% | -4.0 | 价格高度敏感 |

### 3.2 实现
- 场次级别: `repeat_ratio` 已是代理变量（V3已用）
- 升级: 按用户历史→预测该用户本场购买概率→汇总到场次预测

## Phase 4: 热力定价 🗺️

### 4.1 核心洞察
四层331区 713张/场（最热）vs 一层前排均价¥650（溢价空间）
→ 不同区段不是同一产品，不能统一调价

### 4.2 热力加权定价
```
不是"全场统一调 X%"
而是:
  热区(331/310/332): +5% → 需求几乎不减
  中区(二层): 基准价
  冷区(边角): -10% → 消化库存
```

### 4.3 前后排梯度
一层: 前排(1-10排)占47%，后排(31+)仅6%
→ 前排可加价¥50-100，后排保持基准
