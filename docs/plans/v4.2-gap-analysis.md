## 二、关键差距详解

### 🔴 Gap 1: 分级太粗

**调研建议**:
```
S级(德比): 申花 → 溢价60-80%
A级(强队): 海港/泰山/蓉城 → 溢价20-40%
B级(中游): 天津/浙江/河南/武汉/长春... → 基准
C级(弱队): 升班马/保级队 → 降10-20%
```

**当前**: A={申花,海港,泰山,蓉城}，B=其余。申花和海港同价。

**影响**: 申花德比(15,482张, 场均1.56×)和海港(6,003张, 0.60×)需求差2.6倍，却在同一档定价——要么申花定低了，要么海港定高了。

**修正**: 
```python
S_TIER = {"上海申花"}         # 德比
A_TIER = {"上海海港", "山东泰山", "成都蓉城"}  # 强队
B_TIER = {"天津津门虎", "浙江", "河南", ...}   # 中游
C_TIER = {"大连英博海发", "青岛海牛", ...}     # 弱队/升班马
```

### 🔴 Gap 2: 死忠区未保护

**调研红线**: "北看台不打折也不高价——这是品牌根基，涨价会摧毁忠诚"

**当前**: 六档(c1-c6)统一参与优化器调价。c6(最贵)和c1(最便宜)用同一个 `demand_multiplier`。

**修正**: 将死忠看台对应的档位从优化器中排除，保持基准价。需确认哪个档位对应北看台。

### 🔴 Gap 3: 弹性一刀切

**调研**: 德比ε≈-0.3, 升班马ε≈-2.0, 差6倍

**当前**: V3模型用ε=-2.5全局常数（来自2025交易数据拟合）

**修正**: 按S/A/B/C分别估计弹性。最低要求：S级手动设ε=-0.5，C级设ε=-2.5，A/B用数据拟合。

### 🟡 Gap 4: 时间维度缺失

**调研**: "购买时间点"是P0数据，"销售速度"是核心需求信号

**当前**: 所有数据是完赛后的最终快照。5/23河南队首日就卖了3,242张——但我们不知道：
- 哪天卖得最快？
- D-7卖出多少 vs D-1卖出多少？
- 工作日场会不会最后几天才爆发？

**修正**: 这不是模型问题，是数据采集问题。需要票务系统记录每笔交易的精确时间戳。当前折中：用预售进度(当前销量/历史同对手最终销量)做粗糙代理。

### 🟡 Gap 5: 比赛重要性

**调研**: `is_last_5_rounds`, `season_stage` 作为特征

**当前**: `season_stage` 是手工滑块（常规/关键战/争冠/保级），不是数据驱动的

**修正**: 用实时积分榜计算"距降级区分数差"和"距亚冠区分差"→自动判断比赛重要性

## 三、修正后的 V4.2 方案

### 阶段 A: 分级修复（立即可做）

```
1. S/A/B/C 四级对手分类
2. 死忠区(c1?)锁定基准价
3. 分级弹性: S=0.5, A=1.5, B=2.5, C=3.0 (初始设定，后续数据校准)
```

### 阶段 B: 2025-Only 模型重建

```
训练集: 2025赛季16场CSL主场
特征(6个): recent_form_5, lost_to_bottom, opp_rank_live, is_derby, is_weekend, is_double
新增: match_importance (用积分榜距降级区/亚冠区分差)
```

### 阶段 C: 2026动态迭代

```
每场赛后: 追加该场 → 重训 → 下一场用新模型
实时排名: fetch_csl_standings() → 动态opp_rank + match_importance
```

### 阶段 D: 时间维度补偿

```
当前折中: 用"该场当前预售量 / 历史同级别场均" 做销售进度指标
远期: 接入票务系统时间戳数据
```
