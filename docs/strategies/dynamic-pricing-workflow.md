# 动态定价 — 线下操作 SOP

> 每场比赛你只需做两件事：赛前告诉我要定哪场 → 赛后告诉我实际数据。其余全部 Claude 处理。

---

## 赛前：出定价卡

**你**：告诉我下场日期和对手，比如"6/27 武汉三镇"。

**Claude**：跑模型，输出一张定价卡：

```
## 6/27 周六 vs 武汉三镇

B级 / S_B档 | 预测 9,200张 | 目标 ¥2,626,285

 T1 角旗     ¥160
 T2 球门后   ¥220
 T3 边路低   ¥300
 T4 边路高   ¥460
 T5 中线低   ¥540
 T6 中线高   ¥1,080

情境: midseason_restart（间歇期后首场，+10%）
```

同时自动保存快照，锁定此刻模型版本和参数，赛后回测用。

**你**：打开票务后台，六档价格填进去。完成。

---

## 赛中（可选）：盯预售

如果后台能看到已售进度，可以中途告诉我："卖了4200张，距比赛48小时"。我会对比历史预售节奏，判断最终上座是偏快还是偏慢，给微调建议。不做也行。

---

## 赛后：反馈 + 更新

**你**：告诉我两个数——实际销量、实际收入。比如"8,900张，¥235万"。有 Excel 更好，没有也够。

**Claude**：做四件事：

1. 对比预测 vs 实际，算偏差
2. 更新 EMA 校准因子（偏差的 20% 吸收到同级预测里，下一场自动生效）
3. 更新 H2 盯盘表（累计收入 vs 目标）
4. 偏差 > 15% 单独分析原因

回复示例：
> 预测 9,200 vs 实际 8,900，偏差 -3.3%。B 级校准 1.00→0.99。累积 MAE 1,005（8场）。

---

## 下一场

循环。校准自动生效，越跑越准。

---

## 一图流

```
赛前: 你"X月X日 vs XX" → Claude定价卡 → 你填后台
赛中: (可选) 你"卖了X张" → Claude判断节奏
赛后: 你"X张 ¥X" → Claude更新校准+H2盯盘
```

---

## 为什么这样做就能回测

每场赛前 Claude 自动保存快照（模型版本 + 输入参数 + 预测值），赛后 parquet 永久存储实际销量，校准因子逐场累积。赛季任何时候说"跑回测"，就能在完整历史上重现预测 vs 实际的逐场链条。
