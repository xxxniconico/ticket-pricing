# 亚冠 ST/AP → 中超等效级别映射（本土认知折扣法）

> 提出：2026-10-20（用户）｜ 实现：`scripts/acl_tier_mapping.py` ｜ 数据：`data/processed/acl_opponent_ratings.json` + 中超 13 场实测标尺

---

## 一、问题

> **用户的逻辑**：亚冠在中国的宣传较弱 → 即使亚冠球队 ST（实力）较高，但因为与国安交手少、球迷不熟悉 → **在北京观众心里形成的 AP（吸引力）很低**。所以"亚洲 S 级"不等于"工体 S 级"。全北在亚洲算 S，在北京观众心里应该是什么级别？

这个问题击中了现有打分方法的**两个结构性缺陷**。

---

## 二、为什么现有 AP 必然偏高

### 缺陷 1：视角错位（**亚洲视角 ≠ 北京视角**）

现用 AP = 40% 品牌力 + 25% 洲际知名度 + 20% 话题 + 15% 稀缺。四项**全是亚足联/洲际视角**的指标：

| 维度 | 现用指标 | 全北得分 | 对北京买票决策的真实作用 |
|---|---|--:|---|
| 品牌力 40% | 亚洲豪门地位 | 85 | 中（知道是强队，但"强"不等于"想看"） |
| 洲际知名度 25% | 亚冠冠军履历 | 85 | **低**（北京观众记不住 K League 冠军年表） |
| 话题 20% | 泛话题 | 65 | 中（无巨星、非恩怨局时话题很弱） |
| 稀缺 15% | 洲际稀缺 | 60 | 中 |

→ 这套指标回答的是「**这个对手在亚洲有多强**」，不是「**北京球迷有多想买票**」。

### 缺陷 2：尺度不可比（**两个坐标系**）

| | 中超 AP | 亚冠 AP |
|---|---|---|
| 构造方式 | 0.35×**历史票房分位** + 0.10×PERF + …（相对分位） | 品牌力/知名度/话题/稀缺（**绝对评估**） |
| 数值上限 | **44.7**（申花，中超最高） | **77.2**（全北） |
| 含义 | "相对国安主场历史对手的位置" | "在亚洲足球体系的地位" |

→ 直接用亚冠 AP 套中超的分级阈值，等于**拿两把不同刻度的尺子量同一个东西**。v3 标定已明确指出："不是差一个常数倍，而是整个赛事的坐标系不同。"

## 三、三种映射方案（已实现两种，均可用）

### 方案 A：弹性衰减（v4 现行，γ = 0.15）

```
Q = 锚 × (AP_asia/66.3)^γ × (ST_asia/63.0)^γ × ctx，  γ = 0.15
```
- γ 标定：2025 ACL2 三场"分档结构跨对手几乎同形、CV 22.3% ≈ 中超残差 21.3%"→ 对手维度贡献 ≈ 0，故把中超弹性（α=0.352）压到 40%；
- 优点：已落地、可复现；缺点：**只压缩差异，不解释为什么**（对业务沟通不友好）。

### 方案 B：本土认知折扣（本方案，d ≈ 0.40）

```
AP_cn = AP_asia × d      （把亚洲 AP 折算回中超 0-45 尺度）
```
- **与方案 A 数学等价**（对数线性下）：`AP^γ_ac = (AP×d)^γ_cn ⟺ γ_ac = γ_cn × d`
- 验证：0.15 / 0.352 = **0.426** ≈ d = 0.40 ✓ 两条路径独立算出了同一个数
- 优点：**能直接回答"相当于中超哪个级别"**；缺点：d 只有 1 个实测点。

### 方案 C：需求反推（最可靠，不依赖任何主观打分）

把亚冠各场的**去情境 q_norm** 直接插进**中超 13 场实测票房标尺**：

| 中超级别 | 实测 q_norm 均值 | 引擎基准 |
|---|--:|--:|
| S | 12,799 | 12,600 |
| A | 10,669 | 10,900 |
| B | **8,441** | 8,200 |
| C | **6,458** | 5,700 |

→ 得到"等效中超级别"。**这是唯一有 MD1 实测支撑的映射**，下文以此为主口径。

---

## 四、实证：d 的标定

### 标定路径 1：由 γ 反推（间接）
`d = γ_ac / α_cn = 0.15 / 0.352 = 0.426`

### 标定路径 2：由 MD1 反推（直接）
MD1 浦项的亚洲 AP = 66.3，实测去情境 q_norm = 6,367，落在中超 C 级标尺（6,458 = 99%）。
中超 C 级对手的 AP 区间是 **(0, 25)** → 若要浦项的"等效 AP"落进这个区间：
`66.3 × d ∈ [20, 25] → d ∈ [0.30, 0.38]`

### 取值
**d = 0.40**（两条路径的中值偏保守，落在 [0.30, 0.43] 区间内）。
⚠️ 单点标定，置信度低；**MD3（全北）赛后为第二个样本，可把 d 收窄到 ±0.05**。

## 五、映射表（2026-10-20 口径）

| 场次 | 对手 | 亚洲级别 | 亚洲 ST/AP | **北京感知 AP** | 去情境 q_norm | **等效中超级别** | 占 C 标尺 |
|---|---|---|--:|--:|--:|:--:|--:|
| 10-27 | **全北现代** | **S** | 76.1 / 77.2 | **30.9** | 7,037 | **C+** | **109%** |
| 09-15 | 浦项铁人（实测） | A+ | 63.0 / 66.3 | 26.5 | 6,367 | **C** | 99% |
| 02-16 | 纽卡斯尔喷气机 | B | 63.9 / 45.3 | 18.1 | 6,027 | **C** | 93% |
| 12-01 | 拉查武里 | B- | 55.2 / 39.0 | 15.6 | 5,765 | **C-** | 89% |

### 核心结论

> **亚洲 S 级的全北，在北京观众心里只相当于中超的 C+ 级 —— 大约是"中超保级队偏上"的水平（对标武汉三镇 / 辽宁铁人 / 深圳新鹏城这一档），不到中超 B 级（8,441，差 16%），更不到 A 级（10,669）或 S 级（12,799）。**

**四场亚冠主场，没有一场达到中超 B 级的票房水平。**

### 为什么这个结论可信（不只是模型自证）

1. **MD1 是实测锚**：浦项的 6,367 不是模型算出来的，是 5,476 张真实成交量去掉 midweek 效应后得到的；
2. **三条口径互相印证**：v2 引擎折减（×0.566）、v3 台阶映射（6,250）、v4 认知折扣（6,052）都指向同一区间；
3. **2025 二级联赛是旁观证据**：三个完全不同国家的对手（港超/越南/澳超），分档结构极差 ≤5pp、波动 CV ≈ 噪声 → 对手"是谁"对北京观众几乎不影响决策。

## 六、对定价与运营的含义

### 6.1 票价：维持 B 级，**不要按"等效 C+"降价**

这是最反直觉的一条。既然需求只有 C+，为什么票价还用 B 级（199/299/459/539/688）？

| 反事实 | 证据 | 结论 |
|---|---|---|
| MD1 降价敏感性 | v2.5 §十三·19：各档 −13%（弹性 −1.5）→ 合计仅 **+4.8 万** | **降价换不来量** |
| C 级定价反事实（10-18 青岛场） | 分级错 ≠ 收入损失，是预测失真 | 用 C 级价卖 → 量不够补价差 |
| MD1 同价档对照中超 | T3/T4/T5 售罄率仅中超同价的 52%/23%/27% | 瓶颈在**需求侧**（周中+认知+触达），不在价格 |

→ **亚冠首年"高价低量"是理性选择**：守住中超的价格锚，不因为"对手不被认识"就打折（打折也不会来人，还会毁掉 MD6/MD8 和明年的价格锚）。

### 6.2 营销：不能卖"亚洲豪门"，要卖"国安主场"

既然北京观众的等效认知只有 C+：

| ❌ 无效叙事 | ✅ 有效叙事 |
|---|---|
| "亚洲冠军全北来访" | "国安亚冠两连胜，来看看能走多远" |
| "K League 豪门对决" | "工体周二夜，¥199 看亚冠" |
| "复仇 2015"（若球迷记不住） | "带朋友来，199 两个人也不贵" |

**依据**：MD1 买家画像——散票买家中 **38.7% 是库内零记录真新客**（高于杯赛 34.3%），且新客更愿买高价档（16.2%）、结伴率更高（42.1%）。→ 卖"氛围/体验/性价比"，不卖"对手名头"。

### 6.3 库存：C+ 级需求下的容量余量

6,052 张 ÷ 可售 21,215 座 = 28.5%。**后备扩容池 4,473 座（307/327/328/329/331/332）本场不需要开**——开售反而稀释上座观感（v2.5 减供方案 v2 的"保量不减供"原则）。

## 八、局限（诚实标注）

1. **d = 0.40 只有 1 个实测点**（MD1 浦项），区间 [0.30, 0.43]，MD3 后才可收窄；
2. **需求反推 ≠ 认知度**：q_norm 里同时混入了价格、档期（周二）、宣传强度，不能全部归因于"认知折扣"。本方法只能回答"需求等效"，不能回答"为什么低"；
3. **亚冠与中超的档期差异未完全剥离**：中超 B 级标尺来自周末/暑期场次，亚冠全是周中，ctx 0.86 只做了一个常数修正；
4. **ST 的跨联赛可比性未验证**：K League 第 3 与中超第 3 的实力是否同分，本项目无跨联赛 ELO 链；
5. 2025 ACL2 三场对手从未做 ST/AP 评估（ELO 缺失），故 γ/d 的标定只能用 2026 MD1 起的样本。
